## 1. What is DONE and fully working

### Booking (COMPLETE)

State machine with VALID_TRANSITIONS (`bookings.ts:28`), create → transition → authorize/capture/statusCallback → refund (wallet-returning). Multi-mode: group, emergency, QR, menu, reschedule, calendar sync.

### Wallet (COMPLETE)

`topUp` never mints (PENDING + `idempotencyKey`), spend via capture decrement, cashback worker idempotent (`cashback_<id>`). Money-integrity-pinned.

### Marketplace & stores (COMPLETE with one gap)

Registration wizard → `providerSubmission` PENDING_REVIEW → admin `providerReview.decide` verifies the vendor (`providerReview.ts:141-151`) → products → store checkout → PENDING_FULFILLMENT orders → `fulfillOrder` accrues payouts → payouts/disputes UI. Covered by store-approval / store-deals / store-settlement tests. **Gap: dispute resolution marks the order REFUNDED but moves no money.**

### Loyalty & gamification (COMPLETE, referral PARTIAL)

Points, punch-card, bingo, cashback, streaks, challenges, leaderboards. **Referral race: leaderboard/myRank/share only — the prize is a string, no award/payout path.**

### Wellness & lifecycle (COMPLETE)

Cycle tracker (predictions-tested), menopause, postpartum, lifeStage journeys, wellness hub, journals, surveys, courses, expenses, kids K1–K4, hijab-care, bridal concierge.

### Flash deals (COMPLETE)

Atomic `updateMany` + rollback; claims guarded. **No dedicated test file (gap).**

### Realtime & notifications (COMPLETE)

Socket rooms + WebRTC, per-socket rate limits; SMS/WhatsApp/push/email all fail-closed or degrade gracefully.

### ZATCA (PARTIAL → live-gated)

Full local pipeline: crypto-stamped invoice + QR, report/clear, VAT CSV, dashboard, audit trail, CSID request. Live clearance gated on `ZATCA_API_KEY/SECRET` (simulate stub in dev).

### MyFatoorah (sandbox-ready, live-gated)

Facade complete (countries/cities/shipping/charge), fail-closed; live = `FATOORAH_API_TOKEN` (user-gated).

### AI (PARTIAL)

`ai.chat` = real OpenAI with try/catch; content-gen = OpenAI→mock fallback; recommendations = pure DB co-occurrence; **virtualTryOn `saveSession` = NOT_CONFIGURED stub (results not persisted)**.

### Web/Mobile surfaces

- Web: 44 admin panels (analytics, finance/ZATCA/payouts, CMS, feature-flags, observability, queues), 12 tech dashboards, `/store` shell, blog+CMS, SEO on 17 pages, i18n locale split (0 violations; 2 demo-string exceptions).
- Mobile: booking/wallet/marketplace/wellness/loyalty/subscriptions/gift-cards/chat/try-on present; EAS pipeline ready (dev-client APK + preview + production profiles, OTA via expo-updates); admin core screens present.

## 4. Recommended next steps (by impact)

1. **Close the money gaps (#1–#4)** — gift-card + subscription purchase must take payment (wallet or gateway); dispute refunds must move money; referral prizes need an award path. This is the "never free money" rule being violated today.
2. **Fix the visible errors (#5–#8)** — a recommendations-list procedure fixes gift-guide; one-line nav fix; calendar OAuth; descAr.
3. **Delete the prod-compose backup mount or create the script (#11)** — a missing file referenced in prod config.
4. **SEO long tail (#13)** — continue the generateMetadata sweep.
5. **State-coverage sweep (#12)** — 126 pages without error handling is the largest polish surface.
6. **Kill the stubs or hide them (#14–#15)** — "coming soon" endpoints in production routers.
7. **Barrel the 28 unbarreled routers (#16)** — keeps the extraction seams honest.
